# Permutation groups

`PermutationGroup()` is the group generated by permutations, given as
arguments or as one list, as SymPy's `PermutationGroup`: generators are
resized to a common degree, duplicates (with `dups = TRUE`) and
identities (when there are other generators) are dropped. The group
keeps SymPy's caches, so the base and strong generating set computed by
the Schreier-Sims algorithm, the state of the product replacement
generator and the known properties persist on the object.

## Arguments

- ...:

  Permutations or one list of permutations.

- dups:

  Remove duplicate generators.

- degree:

  Degree to resize generators of different sizes to.

- G, H, K, N:

  Permutation groups.

- gen_count, iterations:

  Size and warm up of the product replacement state.

- .random_prec:

  Precomputed choices, as SymPy's `_random_prec`.

- base:

  A base (0 based points).

- strong_gens:

  A strong generating set.

- pos:

  Position of the base points to swap.

- randomized:

  Use the randomized version.

- transversals, basic_orbits, strong_gens_distr:

  Precomputed data.

- other:

  A group, a list of permutations or a permutation.

- g:

  A permutation (or its array form).

- factor_index:

  Return the base images instead of the factors.

- original:

  Express in the original generators.

- rank:

  A rank.

- af:

  Return array forms.

- method:

  `"coset"` (Schreier-Sims) or `"dimino"`.

- strict:

  Require equal degrees.

- p:

  A prime.

- eps:

  Error bound of the Monte Carlo test.

- gr:

  The group to test normality in.

- points:

  Points of the block or of the stabilizer.

- x:

  A permutation.

- t:

  The variable of the Molien series (default the symbol `t`).

- k:

  Number of random elements per round.

- alpha:

  A point, or a vector of points for the action on tuples or sets.

- action:

  `"tuples"`, `"sets"` or `"union"` for a vector `alpha`.

- beta:

  A point.

- schreier_vector:

  A Schreier vector of `alpha`.

- pairs:

  Return (point, permutation) pairs.

- incremental:

  Use the incremental Schreier-Sims algorithm.

- n:

  For `make_perm()`, the number of generators to multiply, or a vector
  of generator indices to use in turn.

- seed:

  `NULL` (the global generator), an integer seed, or a vector of values
  to use in turn, as SymPy's `_randrange`.

- gens:

  Generators to use instead of the group's.

- slp_dict:

  Also return the straight line programs of the strong generators.

- consec_succ:

  Number of consecutive successful sifts to stop at.

- prop:

  A predicate on permutations defining the subgroup.

- tests:

  Optional list of level tests.

- init_subgroup:

  A known subgroup of the result.

## Value

A `PermutationGroup`, list, vector, integer or logical.

## Details

The functions below are SymPy's methods. Properties:
`group_generators()`, `group_degree()`, `group_identity()`,
`group_order()`, `group_elements()`, `is_abelian()`, `is_cyclic()`,
`is_dihedral()`, `is_trivial()`, `is_solvable()`, `is_nilpotent()`,
`is_perfect_group()`, `is_polycyclic()`, `is_symmetric_group()`,
`is_alternating_group()`, `is_alt_sym()`, `is_transitive()`,
`is_primitive()`, `transitivity_degree()`, `max_div()`,
`is_elementary()`. Base and strong generating sets: `group_base()`,
`strong_gens()`, `basic_orbits()`, `basic_transversals()`,
`basic_stabilizers()`, `schreier_sims()`, `schreier_sims_incremental()`,
`schreier_sims_random()`, `schreier_vector()`, `baseswap()`. Membership
and cosets: `group_contains()`, `coset_factor()`, `coset_rank()`,
`coset_unrank()`, `coset_transversal()`, `coset_table()`,
`generator_product()`, `is_subgroup()`, `group_index()`, `subgroup()`,
`group_equals()`. Orbits: `orbit()`, `orbits()`, `orbit_rep()`,
`orbit_transversal()`, `minimal_block()`, `minimal_blocks()`. Subgroups:
`stabilizer()`, `pointwise_stabilizer()`, `centralizer()`,
`group_center()`, `normal_closure()`, `group_commutator()`,
`derived_subgroup()`, `derived_series()`, `lower_central_series()`,
`composition_series()`, `sylow_subgroup()`, `subgroup_search()`,
`is_normal()`, `quotient_group()`, `abelian_invariants()`. Elements:
`generate_dimino()`, `generate_schreier_sims()`, `group_generate()`,
`conjugacy_class()`, `conjugacy_classes()`, `molien()`. Random elements,
drawn from the generator that
[`sympy_seed()`](https://adamrsophie.github.io/symcompR/reference/sympy_seed.md)
seeds: `random_pr()`, `random_stab()`, `group_random()`, `make_perm()`.

## Examples

``` r
G <- DihedralGroup(4)
group_order(G)
#> [1] 8
group_base(SymmetricGroup(4))
#> [1] 0 1 2
orbits(PermutationGroup(Permutation(0, 1), Permutation(2, 3)))
#> [[1]]
#> [1] 0 1
#> 
#> [[2]]
#> [1] 2 3
#> 
```
