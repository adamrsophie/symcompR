# Content and primitive part

`primitive(f)` returns `list(content, primitive)`, and `terms_gcd()`
pulls out the greatest common monomial and numeric factor.

## Usage

``` r
primitive(f, ...)

content(f, ...)

terms_gcd(f, ...)
```

## Arguments

- f:

  An expression.

- ...:

  Generators.

## Value

A list or an expression.
