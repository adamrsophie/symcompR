# Reidemeister Schreier presentations

Returns the generators and relators of a presentation of the subgroup of
the `FpGroup` `fp_grp` generated by the words `H`, simplified as in
SymPy's `reidemeister_presentation()`. With `homomorphism = TRUE` the
images of the new generators in `fp_grp` are returned as a third
element.

## Usage

``` r
reidemeister_presentation(fp_grp, H, C = NULL, homomorphism = FALSE)
```

## Arguments

- fp_grp:

  An `FpGroup`.

- H:

  A list of words.

- C:

  A coset table of `H` to use.

- homomorphism:

  Also return the images of the generators.

## Value

A list of two (or three) tuples.

## Examples

``` r
g <- free_group("x, y")
x <- g[[2]]; y <- g[[3]]
f <- FpGroup(g[[1]], list(x^3, y^5, (x * y)^2))
fp_str(reidemeister_presentation(f, list(x * y, x^-1 * y^-1 * x * y * x)))
#> [1] "((y_1, y_2), (y_1^2, y_2^3, y_2*y_1*y_2*y_1*y_2*y_1))"
```
