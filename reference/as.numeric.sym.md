# Convert a numeric expression to an R value

Convert a numeric expression to an R value

## Usage

``` r
# S3 method for class 'sym'
as.numeric(x, ...)

# S3 method for class 'sym'
as.double(x, ...)

# S3 method for class 'sym'
as.complex(x, ...)
```

## Arguments

- x:

  A `sym` expression without free symbols.

- ...:

  Ignored.

## Value

A double or complex number.
