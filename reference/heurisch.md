# The heuristic Risch algorithm

Ports of SymPy's `heurisch()` and `heurisch_wrapper()`
(sympy/integrals/heurisch.py): a candidate antiderivative with
undetermined coefficients over the differential field generated by the
components of the integrand, solved as a linear system.

## Usage

``` r
heurisch(
  f,
  x,
  rewrite = FALSE,
  hints = NULL,
  mappings = NULL,
  retries = 3,
  degree_offset = 0,
  unnecessary_permutations = NULL,
  try_heurisch = NULL
)

heurisch_wrapper(
  f,
  x,
  rewrite = FALSE,
  hints = NULL,
  mappings = NULL,
  retries = 3,
  degree_offset = 0,
  unnecessary_permutations = NULL,
  try_heurisch = NULL
)
```

## Arguments

- f:

  The integrand.

- x:

  The variable.

- rewrite:

  Rewrite trigonometric functions with `tan` and `tanh`.

- hints:

  `NULL`, an empty list for the built-in special function hints, or a
  list of extra terms.

- mappings, retries, degree_offset, unnecessary_permutations,
  try_heurisch:

  As SymPy.

## Value

The antiderivative or `NULL`.

## Examples

``` r
x <- Symbol("x")
heurisch(x*cos(x), x)
#> x*sin(x) + cos(x)
```
