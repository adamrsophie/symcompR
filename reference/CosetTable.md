# Coset tables and coset enumeration

`CosetTable(G, H)` starts a coset table of the subgroup generated by the
words `H` in the finitely presented group `G`. `coset_enumeration_r()`
runs the relator based (HLT) strategy, `coset_enumeration_c()` the coset
table based (Felsch) strategy and `modified_coset_enumeration_r()` the
HLT strategy that also records the subgroup words. The table is
`C$table`, a list with one integer vector per coset (zero based, `NA`
for an undefined entry); `C$p` is the coincidence vector. The `ct_*`
functions are the methods of SymPy's `CosetTable` (`ct_scan_and_fill`,
`ct_compress`, `ct_standardize`, ...); `x` is a generator or inverse of
a generator, cosets are zero based.

## Usage

``` r
CosetTable(fp_grp, subgroup, max_cosets = NULL)

ct_omega(C)

ct_n(C)

ct_A(C)

ct_copy(C)

ct_is_complete(C)

ct_define(C, alpha, x, modified = FALSE)

ct_define_c(C, alpha, x)

ct_scan_c(C, alpha, word)

ct_coincidence_c(C, alpha, beta)

ct_scan(C, alpha, word, y = NULL, fill = FALSE, modified = FALSE)

ct_scan_check(C, alpha, word)

ct_merge(C, k, lamda, q, w = NULL, modified = FALSE)

ct_rep(C, k, modified = FALSE)

ct_coincidence(C, alpha, beta, w = NULL, modified = FALSE)

ct_scan_and_fill(C, alpha, word)

ct_scan_and_fill_c(C, alpha, word)

ct_look_ahead(C)

ct_process_deductions(C, R_c_x, R_c_x_inv)

ct_process_deductions_check(C, R_c_x, R_c_x_inv)

ct_switch(C, beta, gamma)

ct_standardize(C)

ct_compress(C)

ct_conjugates(C, R)

ct_coset_representative(C, coset)

ct_modified_define(C, alpha, x)

ct_modified_scan(C, alpha, w, y, fill = FALSE)

ct_modified_scan_and_fill(C, alpha, w, y)

ct_modified_merge(C, k, lamda, w, q)

ct_modified_rep(C, k)

ct_modified_coincidence(C, alpha, beta, w)

coset_enumeration_r(
  fp_grp,
  Y,
  max_cosets = NULL,
  draft = NULL,
  incomplete = FALSE,
  modified = FALSE
)

modified_coset_enumeration_r(
  fp_grp,
  Y,
  max_cosets = NULL,
  draft = NULL,
  incomplete = FALSE
)

coset_enumeration_c(
  fp_grp,
  Y,
  max_cosets = NULL,
  draft = NULL,
  incomplete = FALSE
)
```

## Arguments

- fp_grp:

  An `FpGroup`.

- subgroup, Y:

  A list of words generating the subgroup.

- max_cosets:

  Largest number of cosets.

- C:

  A coset table.

- alpha, beta, gamma, k, lamda, coset:

  Cosets.

- x:

  A generator or inverse generator (a word of length one).

- modified:

  Use the modified methods.

- word, w:

  A word.

- y:

  A word of the subgroup free group (modified methods).

- fill:

  Define new cosets while scanning.

- q:

  The coincidence queue (an integer vector).

- R_c_x, R_c_x_inv:

  Lists of relator conjugates.

- R:

  A list of relators.

- draft:

  A coset table to start from.

- incomplete:

  Return a partial table when `max_cosets` is reached.

## Value

A `CosetTable` (an environment), or what the SymPy method returns.

## Examples

``` r
g <- free_group("x, y")
x <- g[[2]]; y <- g[[3]]
f <- FpGroup(g[[1]], list(x^3, y^3, x^-1 * y^-1 * x * y))
C <- coset_enumeration_r(f, list(x))
ct_compress(C); ct_standardize(C)
fp_str(C$table)
#> [1] "[[0, 0, 1, 2], [1, 1, 2, 0], [2, 2, 0, 1]]"
```
