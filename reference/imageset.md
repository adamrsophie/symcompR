# Set aliases

`imageset()` is
[`ImageSet()`](https://adamrsophie.github.io/symcompR/reference/sets.md),
`Contains(x, s)` the membership condition, and `PowerSet(s)` the set of
all subsets of a finite set.

## Usage

``` r
imageset(lam, base)

Contains(x, s)

PowerSet(s)
```

## Arguments

- lam, base, x, s:

  Arguments.

## Value

A set or boolean.
