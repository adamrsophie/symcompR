# Convert a set to a relational condition

Convert a set to a relational condition

## Usage

``` r
as_relational(s, x, ...)
```

## Arguments

- s:

  A set.

- x:

  The variable.

- ...:

  For a
  [`ProductSet()`](https://adamrsophie.github.io/symcompR/reference/sets.md),
  one more variable per further factor.

## Value

A boolean expression.
