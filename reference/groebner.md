# Groebner bases

`groebner(F, gens, order)` computes the reduced Groebner basis of the
ideal generated by the polynomials `F`, with `"lex"`, `"grlex"` or
`"grevlex"` monomial order, like SymPy's `groebner()`.
`is_zero_dimensional()` tests whether the corresponding system has
finitely many solutions.

## Usage

``` r
groebner(F, ..., order = "lex")

is_zero_dimensional(F, ...)
```

## Arguments

- F:

  A list of polynomial expressions.

- ...:

  Generators, in order.

- order:

  Monomial order.

## Value

A list of expressions.

## Examples

``` r
x <- Symbol("x"); y <- Symbol("y")
groebner(list(x^2 + y^2 - 1, x - y), x, y)
#> [[1]]
#> x - y
#> 
#> [[2]]
#> 2*y^2 - 1
#> 
#> attr(,"gens")
#> attr(,"gens")[[1]]
#> x
#> 
#> attr(,"gens")[[2]]
#> y
#> 
#> attr(,"order")
#> [1] "lex"
```
